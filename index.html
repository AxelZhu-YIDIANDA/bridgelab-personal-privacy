1. 应用与适用范围

BridgeLab Personal 是 Threads 账号 @zhuaxel 的持有人创建或合法管理的第三方应用，使用 Threads 官方 API，仅用于本人账号管理、数据核对和开发测试。本应用不是 Meta 或 Threads 官方客户端，不对外提供账号代运营服务。

截至本版本制定时，应用已完成授权凭据及权限诊断，业务数据同步尚未开启。后续读取须先完成必要的数据处理条件核查，并由本人确认目标账号；本说明的公开发布本身不会启动同步。

2. 处理哪些数据、用于什么

当前授权诊断处理必要的凭据与诊断信息，包括授权有效性、权限范围、应用显示名及账户标识。拟开展的本人账号只读验证范围如下：

  • 基本资料：账号 ID、用户名、显示名、简介及头像链接等接口实际返回的字段。
  • 本人帖子：首轮最多 10 篇近期帖子的 ID、文本、发布时间、链接、媒体类型及相关字段。
  • 帖子回复：其中最多 2 篇本人帖子的可访问回复，可能包括回复文本、用户名、时间、链接及关联关系。回复可能来自他人，不视为本人的创作。
  • Insights：对应范围内实际可访问的浏览、点赞、回复、转发、引用及粉丝数等指标，以及统计口径、采集时间、来源与缺失原因。

这些数据仅用于本人账号管理、建立首次快照、核对指标和记录数据缺口。缺失值不会伪造为零，当前累计值不会被当作历史观测。数据不用于售卖名单、广告画像、跟踪其他账号或自动社交操作。

本版本仅使用 threads_basic、threads_read_replies、threads_manage_insights 三项读权限。首轮数量是内部测试范围，不代表平台的配额或安全阈值。

3. 保存与保护方式

授权凭据保存在负责人 Windows 电脑的受保护本地配置中，使用当前用户加密与文件访问权限保护；必要请求执行时短暂存在于进程内存。这不能隔离同一系统用户下的全部高权限进程。

业务数据、来源记录和计算结果拟保存在本机结构化文件中；不宣称所有业务文件均已加密。模拟数据与真实数据分开保存。快照追加保存用于核对来源和变化，但不代表永久保留或不可删除。

本版本不提供公开数据看板，不把账户业务记录上传到公开说明网站，也不在公开页面、日志或聊天中展示授权凭据。

4. 外部服务与数据分享

Threads API 请求发往 Meta 官方服务。当前使用 Codex 协助配置与排错时，仅提供必要的接入状态、权限名称及去除秘密的诊断结果；尚未通过本项目向模型提供真实 API 帖子、回复原文或 Insights 载荷。真实 MCP 业务输出保持关闭。

若以后需要向模型提供业务摘要，将先核实适用的平台用途、服务条件及必要授权，限定数据范围并更新说明。摘要、匿名化或派生结果不被自动视为不受平台条款约束的数据。

本公开说明页面由 GitHub Pages 托管。页面不设置表单、广告、分析脚本或跟踪资源。GitHub 会为安全目的记录访问者 IP 地址；相关处理由 GitHub 按其隐私声明说明。负责人不承诺关闭或代为删除 GitHub 自身持有的服务日志。

5. 数据保留原则

数据只在上述必要用途持续存在期间保留。负责人在本轮验证结束、用途发生变化、停止使用应用，以及收到适用的本人或 Meta 删除要求时，人工复核保留必要性；不再必要的数据应及时删除。

目前没有自动清理任务，也没有承诺固定的自动删除天数。未设置固定天数不代表无限期保存。确有适用法律要求保留特定记录时，应说明依据、限制使用，并在该要求结束后处理删除。

6. 数据删除说明

撤销授权不会自动删除已保存的本地记录。 本人可在 Threads 官方“网站权限”中移除 BridgeLab Personal，以撤销后续 API 访问。已保存的凭据、诊断记录和业务快照仍需另行人工删除。

如需删除本应用持有的数据，请发邮件至 zsp5413@gmail.com，标题可写“BridgeLab Personal 数据删除请求”。

  1. 提供关联的 Threads 用户名或相关帖子链接，并说明希望删除的数据范围。请勿发送 Token、App Secret、密码、验证码或其他授权秘密。
  2. 负责人仅核对处理请求所必需的身份及记录信息；信息不足时，通过该联系渠道沟通补充。
  3. 核对后人工处理本应用控制的对应原始快照、派生结果、索引、相关诊断记录及副本，并告知处理结果。如存在适用的保留要求，应说明原因和范围。
  4. 需要停止使用应用时，另行处理本地凭据；不会把仅撤销 Threads 授权当作本地数据已全部清除。

本应用目前没有自动删除回调。上述流程针对本应用控制的记录，不会删除 Threads 平台上的原帖或回复，也不承诺代为删除 Meta、GitHub 或 Codex 各自独立持有的记录。本应用不通过社交写接口替本人删帖。
